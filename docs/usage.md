# 使用指南

[项目首页](../README.md) · [Ubuntu 部署](ubuntu-deployment.md) · [架构与目录](architecture.md) · [贡献指南](../CONTRIBUTING.md)

## 启动与停止

首次使用先完成 [Ubuntu 部署](ubuntu-deployment.md)。在项目根目录执行：

```bash
./cweb                      # 后台启动，优先打开 Edge
./cweb status               # 查看状态与地址
./cweb logs                 # 查看日志
./cweb start --no-browser    # 手动打开浏览器
./cweb start --port 4781     # 指定端口
./cweb stop                 # 正常停止；有任务运行时会拒绝
./cweb restart              # 正常重启
```

默认地址为 `http://127.0.0.1:4780`。重复启动会复用同一服务，关闭启动终端后仍可使用。端口被其他程序占用时会报错，不会终止该程序。只有明确要中断任务时才使用 `./cweb stop --force`。

`npm start`、`npm run status` 和 `npm run stop` 提供相同的启动、状态和停止操作。需要排查启动过程时，可用前台模式 `npm run serve -- --port 4781`，按 `Ctrl+C` 退出。

可在启动终端指定 `CWEB_CODEX=/path/to/codex`、`CWEB_BROWSER=/path/to/browser` 或 `CWEB_DATA_DIR=/path/to/data`。已有服务会保留启动时的环境，更改后需在任务结束时正常重启。

从任意终端使用 `cweb` 的可选安装方式见 [部署指南](ubuntu-deployment.md#常用命令)。安装入口会写入用户目录，不是运行网页的必要步骤。

## 工作区与原生会话

在网页中选择本机项目文件夹，无须在启动命令中预先指定工作区。文件夹选择器支持单击选择、双击进入、面包屑、筛选和隐藏目录显示。

侧栏按工作区组织会话，支持搜索、重命名、归档和恢复。工作区分组由用户手动开合，收到新消息不会改变开合状态。工作区与组内会话可拖拽排序，也可使用 `Alt+↑/↓` 调整；这些偏好保存在浏览器中。完成绿点表示未读，点开会话后清除；橙点表示等待回复。

默认与启动环境中的 Codex CLI 共享原生历史：使用已设置的 `CODEX_HOME`，否则为当前用户的 `~/.codex`。可以在终端用 `codex resume <会话 ID>` 继续，网页顶部提供复制命令入口。网页获得焦点和定期刷新时会重新读取会话列表。

检测到本机原生常驻 app-server 时，cweb 尝试连接该引擎；否则启动自己管理的 stdio app-server。其他客户端仍在执行同一会话时，先完成或停止那一端的任务，再在网页继续。关闭 cweb 不会停止它连接的外部原生常驻服务。

## 输入、附件与 Skills

输入框按内容自动增高。消息提交后先显示本地气泡并清空输入框，等待 CLI 回执时可以继续写下一条；迟到的回执不会清除新草稿，未确认发送的消息可以恢复到输入框。

文字、已上传附件引用、所选 Skills、文件引用和编辑中的历史消息按话题保存在当前浏览器。刷新后恢复草稿；保存失败时显示提示。清除站点数据会移除这些草稿，其他设备或浏览器不会自动同步。正在提交的消息刷新后先核对结果，不作为新消息自动发送；结果未知时可以点击「核对结果」。

- `Enter` 发送，`Shift+Enter` 换行；设置中可改为 `Ctrl/⌘+Enter` 发送。
- 执行中 `Enter` 补充指令，`Tab` 排到下一轮。停止任务会取消该会话的待发送队列；队列只保存在当前服务进程中。
- 输入 `@` 选择项目文件，输入 `/` 搜索网页命令与当前工作区的 Skills。
- 输入框左侧「＋」提供 Plan、Goal 和 Skills 入口，并保留正在编辑的草稿。
- Skills 来自 CLI 的发现结果，可多选本轮技能。网页端停用通过会话配置覆盖实现，不改写终端的全局技能配置。

附件可以拖入、粘贴或手动选择。每条消息最多 **10 个附件**，单个最多 **20 MB**。PNG、JPEG、WebP 作为原生图片输入传给 CLI；其他文件提供本地路径，UTF-8 文本不超过 200 KB 时同时附上文本内容。PDF、Office 等内容能否读取取决于模型与 CLI 工具。移除草稿中的附件只取消本轮引用，已上传文件保留以支持历史回看。

## 模型、权限与问答

输入框里的英文推理强度以首字母大写显示，例如 Low、Medium、High、Xhigh、Max、Ultra；发送给 CLI 的原生值仍为对应的小写。

模型、推理强度和权限位于输入框工具栏中。模型和强度菜单支持方向键、输入搜索、`Enter` 确定及 `Esc` 返回。运行期间更换模型用于下一轮，不会改变已开始的生成。新会话默认值与已有会话选项可以分别设置。

权限模式包括只读、工作区可写和完全权限。完全权限允许 CLI 访问本机文件和网络，并关闭逐次审批；应按任务需要选择。文件预览和文件引用仍由网页服务校验工作区真实路径。

原生问题及显式选择问题显示在输入框上方，包含题目、选项和自定义回复框。多道题逐项作答，`Shift+←` 返回上一项；在第一项返回输入框。往返、同标签页刷新或切换会话时保留未提交的异步问答草稿。明确的旧式「问题＋选项列表」也可显示为卡片，普通进度清单、代码及引用示例不会自动变成问题。

MCP 工具发出的表单也显示在输入框上方，支持文本、数值、布尔、单选和多选，并在提交时校验必填项与范围。URL 确认需要用户主动打开页面，之后确认完成；不支持的设备验证或复杂表单会明确说明限制。MCP 表单答案只保存在页面内存，不写入浏览器草稿。

## 分支话题与代码审查

会话顶部的分支按钮以及 `/fork`、`/review` 打开会话操作。用户消息旁的「从此处创建分支」可以直接预选位置。

- **分支话题**：调用原生 `thread/fork`，继承当前历史或某次提问之前的历史，保留原话题。新话题提供返回来源的入口；创建分支本身不会自动恢复旧 Goal。原话题仍可继续使用。
- **原生审查**：调用 `review/start`，可以审查未提交改动、与基础分支的差异、某个提交或自定义范围。过程和结果显示在当前话题，使用 CLI 配置的模型与权限。

分支继承对话历史，**同目录的项目文件仍然共享**；它不会创建 Git worktree。当前话题运行时可从较早位置分支，当前末尾分支和审查需等待本轮结束。提交结果未知时先核对会话列表与运行状态，网页不会自动重复执行分支或审查。

## 连接与诊断

侧栏「额度」与设置中的「状态与额度」读取 Codex 当前账户的额度窗口。普通轮询跳过额外的重置额度详情查询；临时失败或空快照最多重读一次，同时打开的面板共用在途查询。网络、登录、权限或版本不支持分别提示，不再把所有失败都视为「不提供额度」。

在能确认仍是同一账户的情况下，短暂网络故障会保留最多 15 分钟前的成功快照，并显示「上次成功读取」时间。切换账户、登录或断开 CLI 连接后清除内存快照；不会用旧对话用量推测当前额度，也不根据窗口重置时间推断账户已恢复执行权限。

点击侧栏底部连接状态，或使用 `/doctor`，进入「连接与诊断」。面板分别显示浏览器网络、网页事件连接、CLI 引擎和当前模型请求；版本区分网页构建、桥接构建、已安装 CLI 与运行端提供的标识。

浏览器临时断网或事件流中断时，已显示的正文与草稿保留，恢复连接会同步原会话。自动重连采用退避间隔，不重发模型任务。401、429、权限、上下文和网络错误分别给出处理方向。CLI 连接失败时仍能使用诊断入口。

「运行网络诊断」按需执行原生 `codex doctor --json --network-only`，展示配置、网络环境、模型 HTTP 与 WebSocket 检查。「取消诊断」只停止本次检查；「导出脱敏报告」保存版本、最近连接事件和诊断结果，不包含聊天正文。检查结果只反映检查时刻，并不能保证下一次模型请求成功。CLI 不支持 `doctor` 时会提示，普通对话仍可使用。

提交消息后遇到超时或丢失回执时，页面显示「提交结果待核对」。桥接保存有上限的提交指纹与回执，通过消息 ID 查原生记录，避免把同一次提交重复执行；查不到记录也不会直接判定未执行。用户仍可手动恢复草稿，但再次发送前会提示可能重复执行。桥接消息队列目前仍是进程内状态，不在这个持久回执保证内。

服务完全停止时，已打开页面保留恢复提示；需在本机运行 `./cweb start` 或 `npm start`。网页不能通过已经停止的同一个服务修复它自身，也不会为恢复一个话题强制重启共享 Codex 引擎。

## 规划、目标与待办

| 入口 | 用途 |
| --- | --- |
| `/plan` | 切换 CLI 原生规划模式；再次使用切回执行 |
| `/plan 问题` | 以规划模式提交问题；执行中排到下一轮 |
| `/goal` | 查看、创建或管理原生目标 |
| `/goal 目标与验收条件` | 预填目标内容 |
| `/status` | 查看账户状态与额度窗口 |

Goal 支持可选 token 预算、暂停、恢复、编辑和清除，写入 CLI 原生状态并与终端共享。持续推进与目标生命周期由 CLI 管理；不支持相关协议的 CLI 会收到明确提示。已完成目标在新任务开始后收起，仍可从「＋ → Goal」查看。

内置的 [待办便签适配](../bridge/plugins/todo-note/README.md) 为每个会话维护独立任务、当前与下一步、搁置状态和阶段。点击「未关联」会请求当前 agent 读取和关联便签，执行中的请求会排队。新会话使用原生动态工具，已有会话在重新载入时通过会话级本地 MCP 适配器接入。

agent 读写便签并提交完成说明，任务进入「待确认」后由用户批准或驳回。被驳回的任务需要附改进与验证说明后再次提交。实时高亮依赖 agent 将当前焦点设为任务的确切标题，不会推测进度。插件可在设置中停用，停用不删除已保存数据。

## 阅读、消息编辑与通知

正文支持 GFM Markdown、表格、任务列表、代码块，以及 `$…$`、`$$…$$`、`\(…\)`、`\[…\]` 公式。执行步骤默认展示说明，命令与长输出按需展开；最终总结中的代码直接展开。相关默认值可在设置中调整。

设置 → 常规 →「工作步骤收起时机」提供「回答结束后」「下次有新消息时」「不收起」。默认为「下次有新消息时」：本次回答结束后保留步骤，发送下一条新消息时再自动收起先前步骤；回答内容保持可见。同一轮运行中再次发出提问，也会收起之前已结束的步骤；实际仍在运行的工具保持可见。历史失败或中断的步骤在新问题到来后同样收起。手动展开的步骤仍可继续回看，设置会在刷新后保留。

旧对话的过程说明、任务摘要和工具操作统一放进步骤组，提问与最终回答保留在外。收起后会释放步骤详情的页面组件；展开步骤组才生成操作列表，展开单项才显示原始输出、差异或图片，最终回答中的代码照常显示。此策略减少页面渲染开销，不会删除 CLI 会话记录。

长对话按固定大小的窗口展示。在「显示更早的消息」附近继续向上滚动，也能加载上一段；翻页会释放远处的页面组件并尽量保持当前阅读位置。「显示较新的消息」、右侧话题回溯和「回到底部」可继续向后浏览。查看历史时，新输出仍显示在受限的实时尾部，避免连续翻页或后台输出使页面元素无限增加。

聊天区采用固定阅读宽度并适配窗口；长会话先显示最近 60 条，早期内容按需展开。浏览历史时新消息会自动追加，保留当前阅读位置；回溯条位于聊天可读区域右侧中部，内部列表默认定位当前话题，最新话题位于列表底部。处在底部时自动跟随新输出，主动上滚后暂停；点击「回到底部」或主动回到底部可恢复跟随。右侧对话刻度用于预览并定位历史提问。

聊天中的本地文件链接会在网页内打开只读预览，支持绝对路径、相对路径、目录、代码行号和 Markdown 锚点；预览中可切换源码、复制或下载；点击底部「使用默认应用打开」，可交给本机默认软件，目录则在文件管理器中打开。二进制或超过预览大小限制的文件也保留此打开入口。外部网址仍在新标签页打开。可预览当前工作区内的文本文件（最大 512 KB）和栅格图片（PNG、JPEG、WebP、GIF、AVIF，最大 20 MB）；本地图片可用 Markdown 图片语法显示；新回复、流式回答结束或点击「刷新」时读取最新版本，不持续轮询。SVG 按文本预览。明确引用的安全隐藏文档可打开，凭据、私钥和应用运行数据会被拒绝。

用户消息提供复制与编辑入口。编辑先载入输入框，取消会恢复原草稿；发送时才调用 CLI 原生 `thread/revert`，回退选中轮次及后续对话后继续。运行中的任务会先停止，同一轮较早的补充指令会在编辑框中合并保留。**回退对话不会撤销项目文件修改。** 旧版 `legacy` 记录不支持当前 CLI 的原地回退，网页会提示限制。回退前的可读会话快照保存在 `bridge/.data/edit-backups/`。

完成和待回复通知位于浏览器窗口右下角。点击「前往会话」才会展开已折叠的侧栏并跳转；通知不会抢走正在作答的焦点。完成通知可自动收起，待回复通知保留到处理或手动关闭。

时间戳在悬停或键盘聚焦时显示。运行状态和实时用时位于输入框上方，切换、刷新和重连后按可获得的开始时间继续累计，包含等待用户确认的时间。每轮结算显示可获得的耗时与 token 增量；账户额度窗口变化可能包含其他会话，不代表该任务的独占消耗。

同一工作区的不同话题可以并行运行。输入框上方会区分正常执行、压缩上下文，以及 CLI 明确上报的模型请求重试；长时间没有新的进展时显示等待说明，不会据此判定断网或自动停止、重发任务。连接重试的原始说明可悬停查看。明确失败后运行指示会结束；漏收完成事件时，后台定期只读核对该轮原生状态并恢复结果，不重新执行任务。

输入框发送键旁的圆环显示当前话题最近报告的上下文占比。点击可查看输入 token、上下文窗口和剩余比例；未收到有效用量时显示「—」，不会用会话累计 token 代替。圆环显示可独立热更新；服务仍在等待空闲升级时，可以查看用量，快捷压缩会禁用并说明原因。菜单中的「压缩上下文」与 `/compact` 共用原生压缩入口，保留输入草稿；运行、发送或压缩期间不能重复提交。接受请求不代表压缩已完成，用量会在 CLI 再次报告后更新，压缩也不保证移除所有历史图片。

设置 → 常规 →「自动恢复失败的请求」默认开启。对于由网页提交、CLI 已明确报告失败的连接请求，如果本轮尚未执行工具、修改文件或给出最终回复，网页最多自动重试一次，并保留原失败记录。自动重试的消息带有标记；关闭开关、手动停止、归档、编辑或发送新指令会取消尚未发送的恢复。已执行操作、等待审批、额度或权限错误、上下文较大，以及终端等外部客户端发起的请求，留给用户核对后继续；不会为了恢复而自动切换模型、创建话题或删改历史。CLI 正在重试或执行时，网页不会并行重发。

图片默认「按需读取原图」：附件与原图预览照常保留，模型先收到本地路径，需要视觉内容时调用看图工具。这样减少历史图片长期嵌入用户消息并随每次请求上传的负担，不改变原图像素或质量。也可在常规设置切换为「随消息直接发送原图」。此设置只影响之后从网页发送的附件，不会清理既有 CLI 历史中的图片。

网页固定注入的工具指南与动态便签快照分别去重，便签更新不会重复写入整套指南。压缩、回退或连接状态不确定时会保守重新注入，去重缓存只保存指纹。上下文提示使用 CLI 最近报告的输入 token 数与窗口大小，不把累计用量或页面消息数量当成当前请求尺寸；较大时建议整理交接或原生压缩，压缩也不保证移除所有历史图片。

Codex 的 WebSocket → HTTP 降级由 CLI 自身处理；当前桥接没有受支持的接口调快内置供应商的降级次数，因此不会写入无效旧开关或偷偷修改全局供应商配置。自动恢复能够降低常见连接故障的影响，不能保证消除远端服务或网络故障。

## 外观与 GenUI

支持深色、浅色和跟随系统；正文与界面字号分别可调。侧栏可折叠、调整宽度。设置中的「外观与布局」提供环行短线、底边巡航、柔和呼吸、三点律动与仅文字计时五种运行反馈；支持关闭动画，并尊重系统减少动态效果偏好。

内置 [GenUI 适配](../bridge/plugins/genui/README.md)，无需安装 DSH 运行时。通过 `$`、`/genui` 或 Skills 菜单添加 genui，可让模型使用 `dsh-ui` JSON 围栏呈现表单、图表等交互内容。

- `/panel` 打开会话的持久面板；`/panel 需求描述` 请求模型更新面板。
- 启用 GenUI 后创建的会话注册 `render_ui` 和 `validate_dsh_ui`；旧会话可使用围栏渲染。
- 本地表单、筛选、判卷和参数变化不调用模型；需要 agent 处理的 `[genui-action]` 提交到对应会话，执行中排队。
- 重型渲染器按需加载。地图、外部资源依赖相应资源与配置可用性；不运行 DSH 专用侧边服务。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 聚焦输入 / 命令面板 | `Ctrl/⌘+K` / `Ctrl/⌘+Shift+P` |
| 设置 / 新会话 | `Ctrl/⌘+,` / `Ctrl/⌘+Alt+N` |
| 发送 / 换行 | `Enter` / `Shift+Enter`，发送键可配置 |
| 下一轮排队 / 停止 | 执行时 `Tab` / 空输入时 `Esc` |
| 搜索输入历史 | 输入框中 `Ctrl/⌘+R` |
| 复制最近回复 / 选择技能 | 输入框中 `Ctrl/⌘+O` / 空输入时 `$` |
| 选择菜单项 | `↑/↓`、`Enter`、`Esc` |

浏览器专用快捷键仍由浏览器处理。完整可用快捷键见网页设置，cweb 不模拟完整终端。

## 数据与当前边界

网页设置、工作区、便签、附件和附加统计位于 `bridge/.data/`；原生会话与认证由 CLI 管理。Git 不备份这些个人数据。需要迁移、独立会话库或处理登录问题时，参见 [部署与迁移指南](ubuntu-deployment.md#会话凭据与备份)。

目前面向单用户本机访问，服务监听 `127.0.0.1`。尚未提供完整终端模拟、持久消息队列、通用 DSH 插件或完整 MCP 管理及网页内登录。文件预览限制 512 KB，单条文本与差异显示最多 20 万字符；CLI 实验接口、可用模型和功能随所用版本而异。macOS、Windows 未逐一验证。
