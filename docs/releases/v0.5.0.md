# cweb 0.5 · Signal

同时跑几个会话时，你可以切回编辑器继续工作。在「设置 → 常规」打开「会话完成桌面通知」，并允许浏览器发送通知。保留一个 cweb 标签页，任一会话处理完一轮，桌面就会显示会话标题。点击横幅可以回到对应会话。

- **看团队交付。** 负责会话核对整体任务后，可以单独发一条完工通知，说明交付内容和验收结果。即使隐藏了团队交流，你也能在负责会话里回看摘要。
- **直接处理审批。** 在输入框上方点「查看并审批」即可核对请求。要把已送达的任务交给其他成员，可在「审批 → 全部记录」选收件人、修改正文并确认转发。启用 AI 风险判断时，由发件人的直属上级审核，最高负责人的请求交给用户。
- **按需阅读团队消息。** 在会话顶栏点「显示团队」或「隐藏团队」，可以切换个人对话与完整记录。设置按工作区保存在当前浏览器。

## English

Enable **会话完成桌面通知** (desktop notifications) under **设置 → 常规** (Settings → General) and allow notifications in your browser. Keep a cweb tab open. When any conversation finishes a turn, click its desktop banner to return to that conversation.

A team lead or task owner can also publish a verified delivery summary. It stays visible even when team traffic is hidden. You can review requests above the composer or forward a delivered message from the approvals history. With AI risk review enabled, the sender’s supervisor reviews the request. Requests from the top-level lead go to the user.

## 安装与更新 · Install or update

需要 Node.js 24.9+ 和已登录的 Codex CLI。下载并解压源码 ZIP，在解压目录运行以下命令。已有安装请保留运行数据，在任务空闲后重启服务。

With Node.js 24.9+ and an authenticated Codex CLI, extract the source ZIP and run these commands in its directory. For an existing installation, keep your local data and restart cweb once active turns have finished.

```bash
npm run setup
./cweb
```
